# СУЦ Селект Маркета: проверка переноса интерфейса

Эталон: `iPrice-demo.html` и `iprice-frontend.zip` в корне проекта.
`demo.css` взят из архива; селекторы ограничены `.sm-iprice`.
Меню платформы остаётся отдельным. Формулы, права, НДС 22%, закупочная цена
и доставка соответствуют Селект Маркету, а не демонстрационным данным.

## Подключённые возможности

- Главная, цены, рынок, версии расчётов, исходные данные.
- Справка и расширенные фильтры справа; закрытие крестиком, Escape и по фону.
- Цены: товарное и региональное представления, поиск, группы 1С,
  классификация, ценовые зоны, только строки с замечаниями.
- Сервер применяет отбор до пагинации. Товарное представление открывается
  по умолчанию и показывает сохранённые медианные цены товара, как в демо.
  Открытая карточка показывает все регионы товара. Региональная таблица
  показывает новую цену, текущую цену справочно, маржу и отдельную кнопку редактирования.
- Рынок: фильтр ценовых зон в группах и регионах. При сравнении версий фильтр
  зон не применяется. Пороговые значения общие с существующей аналитикой.
- Карточка: регионы, конкуренты расчёта, рынок категории, собственная линейка.
- Карточки рынка: участие Авто / Учитывать / Не учитывать, обязательная причина,
  проверка актуальности версии и пересчёт через существующий API.
- Проверка данных: покрытие последнего прайса закупочными ценами по коду,
  региону и месяцу, незаполненная включённая доставка, отсутствие розничной цены;
  отдельно — ошибки и предупреждения последнего успешного расчёта.

## Значение данных

Ценовая зона определяется по новой действующей цене относительно рынка. Ручное согласование учитывается; логика Ай-Пласта сохранена отдельно. В товарном режиме используются медианы товара; в региональном —
показатели конкретного региона. Варианты фильтров учитывают ценовую зону и
наличие проблем. Показатели главной передают выбранную зону в раздел «Рынок».
Исторические варианты региональных строк не удаляются.

Рынок категории использует активную классификацию, а цены — на дату расчёта.
Это справочный список, не неизменяемый исторический снимок классификации.
Метка участия требует пригодной положительной сохранённой цены конкурента
и применимости хотя бы к одному региону товара. Наличие записи с ошибкой
не означает участие в цене. Собственная линейка берётся
из товаров выбранного расчёта. Неполная классификация показывается отдельным
объяснением, а не как подтверждённое отсутствие аналогов.

Проверка источников не запускает расчёт: она не гарантирует пригодность всех
коэффициентов. Полный набор расчётных ошибок появляется после расчёта.
Отсутствие прайса или успешного расчёта не отображается как успешная проверка.
Регионы закупок сопоставляются без учёта регистра, как при расчёте.
Если карточка объединяет больше 50 позиций конкурента, групповое сохранение
блокируется с объяснением: доступно изменение отдельных позиций ниже карточек.
Частичные запросы для такой группы автоматически не отправляются.

## Локальная проверка

- `scripts/check-select-market-demo.cjs`: исходный CSS совпадает с архивом
  после нормализации области действия; вычисленные стили контрольных элементов
  совпадают; проверка отсутствия влияния на элемент вне СУЦ.
- `scripts/check-select-market-iprice.cjs`: браузерные сценарии прав,
  редактирования, фильтров, представлений, карточек, справки и согласования;
  предупреждения React о повторяющихся ключах считаются ошибкой.
- ESLint и производственная сборка React.
- Django: `python manage.py test select_market --settings=select_market.iprice_test_settings`.
  Тесты границ зон, пагинации, покрытия источников и изоляции моделей находятся
  в `select_market/test_iprice_list_controls.py`.

Проверка CSS относится к контрольным элементам, а не доказывает попиксельное
совпадение каждого экрана при любых данных. На тестовом сервере необходимо
проверить реальные данные и PostgreSQL: пять PostgreSQL-проверок локальный
SQLite-прогон пропускает.

Новых миграций и переменных окружения для этих правок нет. Backend и собранный
frontend нужно переносить вместе: фронт использует новые параметры `/rows/`,
`/analysis/` и маршруты `/health/`, `/products/{id}/market/`, `/products/{id}/own/`.

## Дополнительная сверка структуры и поведения

- Массовая корректировка использует фильтры текущей таблицы. Перед применением проверяются версия расчёта и подпись выбранных строк; изменение состава требует повторного просмотра.
- Добавлены сортировка до пагинации, несколько ценовых зон, отдельное сравнение версий и подробная проверка данных.
- Карточка показывает медианы товара, региональные цены, текущие/расчётные/новые цены покупателей и переходы внутри собственной линейки, включая просмотр из сравнения.
- Ручная цена проверяется сервером до сохранения; показаны оптовые цены и маржа.
- Выгрузки сверки парсеров и проверки источников доступны отдельно; загрузки показывают собственный прогресс и результат.

Браузерные проверки используют тестовые ответы API. Они не заменяют проверку реальных данных, PostgreSQL и нагрузки. Равенство каждого экрана демо целиком автоматическими проверками не доказано: дополнительные требования Селект Маркета (НДС, закупка, доставка, права) сохраняют свои элементы.
