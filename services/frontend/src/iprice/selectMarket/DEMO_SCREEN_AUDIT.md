Ограничения: версия должна присутствовать среди доступных последних 50 расчётов; иначе показывается сообщение, автоматической подмены нет.

Следующее продолжение: пара сравниваемых версий сохраняется в адресе (`snapshot`, `compare_from`). Ссылка без двух разных версий не отправляет запрос сравнения. Раздел «Рынок» восстанавливает разрез, иерархию, путь групп, фильтры, поиск, сортировку и страницу; данные адреса проверяются перед использованием. Браузерные сценарии проверяют перезагрузку регионального разреза и сравнения. Исправлена начальная ревизия при прямом входе, проверка последующих изменений другим пользователем сохранена.

В следующем проходе добавлено адресное сохранение внутренних фильтров сравнения: представление, тип изменения, поиск, фильтры и страница. Карточка хранит версию, товар и регион; выбывший товар открывается из старой версии, региональная строка не подменяется первой доступной. Запрос карточки отменяется при уходе. Сценарий проверяет перезагрузку отфильтрованного сравнения и карточки выбывшего товара, затем возврат браузером к прежнему отбору.

Остаётся окончательная визуальная сверка всех экранов на одинаковых данных. Проверки навигации и CSS не являются доказательством полного визуального совпадения.
