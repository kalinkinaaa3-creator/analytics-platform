# Инструкции пользователей

Поместите в эту папку Word-файлы с точными именами (расширение `.docx`):

- `Аналитика CRM инструкция пользователя.docx`
- `Коммерческий прайс - инструкция пользователя.docx`

В имени коммерческого прайса используется обычный дефис с пробелами по бокам.
Файлы скачиваются кнопками рядом с заголовками соответствующих дашбордов.
Папка `public` включается в сборку фронтенда. После добавления или замены
инструкций пересоберите и разверните фронтенд (либо обновите контейнер,
если проект запускается из Docker-образа). Документы доступны как статические файлы сайта.

До размещения файлов кнопки сообщают, что инструкция пока недоступна.
