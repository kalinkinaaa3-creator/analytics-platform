# Приложение «Исполнитель Тары»

## Установка и запуск

1. Запустите `dist/TaraWorkerSetup.exe` двойным щелчком и нажмите «Установить».
2. Откройте ярлык **Tara Worker** на рабочем столе или в меню «Пуск».
   Ярлыки создаются средствами Windows без PowerShell. Если доступ к каталогу
   ярлыков ограничен, файлы приложения всё равно установлены: используйте кнопки
   «Запустить» или «Открыть папку» в установщике. Подробности находятся в
   `%LOCALAPPDATA%\AnalyticsPlatform\TaraWorker\install.log`.
3. При каждом запуске подтвердите адрес API:
   - тестовый: `http://127.0.0.1:18000/api`;
   - рабочий: `https://finebi.ipt.ls:8443/api` (нужен корпоративный VPN).
4. Укажите служебную карточку Тары. Ссылка сохраняется отдельно для каждого API;
   при следующих запусках её можно оставить или заменить. Допускаются HTTPS-ссылки
   tara.ru и региональных поддоменов. Произвольные сторонние сайты не поддерживаются.
5. Нажмите «Подключить исполнитель». При первом подключении к этому API введите
   его `TARA_WORKER_KEY`. В дальнейшем ключ подставляется из защищённого хранилища.
   Кнопка «Изменить ключ» позволяет заменить его для текущего адреса.
6. Можно выбрать `chrome.exe` уже установленного Chromium через «Выбрать…».
   Путь сохраняется. Личный профиль не используется — открывается отдельный профиль.
   При пустом поле приложение проверит стандартные каталоги Chromium, затем свой браузер.
   При отсутствии Chromium приложение скачает его. На компьютере
   должен быть доступ к серверам загрузки Playwright. Повторно та же версия не скачивается.
7. Откроется отдельный Chromium. Дождитесь карточки; при необходимости выполните
   проверку сайта вручную. Оставьте одну служебную вкладку Тары.
8. После подключения запускайте мастер на дашборде или DAG в Airflow.

Встроены Python и зависимости: отдельно устанавливать Python, pip и Node не нужно.
Установщик предназначен для Windows x64 и устанавливает приложение текущему
пользователю без прав администратора. Автозапуска при входе в Windows нет.

## Остановка

«Остановить» завершает текущую группу и попытку отправки результатов, затем отключает
исполнитель. При закрытии работающего приложения сначала требуется дождаться этой
остановки. Неотправленные результаты сохраняются. Chromium остаётся открытым —
его можно закрыть вручную. Для продолжения нажмите «Подключить исполнитель».

Не запускайте одновременно старый `worker.py` из PowerShell и приложение:
сервер разрешает одного исполнителя. После остановки предыдущего иногда требуется
до 90 секунд до освобождения владения. Компьютер не должен спать во время обхода.

## Хранение и обновление

- Программа: `%LOCALAPPDATA%\AnalyticsPlatform\TaraWorker\<версия-сборки>`.
- Данные: `%LOCALAPPDATA%\AnalyticsPlatform\TaraWorkerData`.
- Ключи защищены Windows DPAPI для текущей учётной записи. Нельзя просто перенести
  файл настроек другому пользователю и использовать сохранённые ключи.
- Профиль Chromium и outbox разделены по API. Старый outbox консольного исполнителя
  автоматически не переносится: дождитесь отправки старых результатов перед переходом.
- Повторная установка той же сборки проверяет контрольные суммы и пропускает
  неизменившиеся файлы. Новая сборка устанавливается отдельно, ярлыки обновляются;
  данные и браузерный профиль сохраняются. Старые версии автоматически не удаляются.
- Для удаления закройте приложение и служебный Chromium, удалите ярлыки и каталог
  программы. Каталог данных удаляйте отдельно только если он больше не нужен.

API должен иметь доверенный HTTPS-сертификат (HTTP допускается только на loopback).
Доступ из браузера к health не гарантирует доверия сертификату со стороны Python.
Проверка TLS не отключается. Подпись издателя для этой локальной сборки не настроена.

## Сборка разработчиком

Из PowerShell запустите `build_windows.ps1`. Для сборки нужны Windows x64, Python
с Tkinter и интернет для зависимостей. Скрипт создаёт отдельную `.build-venv`.
Результат: `dist/TaraWorkerSetup.exe`. Для переноса пользователю достаточно этого
файла; каталоги проекта, ключи и настройки в него не включаются.

## Скачивание с iPrice

В блоке «Парсер Тары» доступна кнопка «Скачать исполнитель для Windows».
Доступ к скачиванию имеют пользователи с правом просмотра iPrice.
Установщик остаётся в `services/parser-browser/dist/TaraWorkerSetup.exe`.
Каталог `dist` подключён к Django только для чтения через Compose.

В Git включён только `dist/TaraWorkerSetup.exe`; остальные результаты сборки исключены.
При развёртывании получите установщик вместе с изменениями проекта,
примените обновлённый Compose для Django и обновите сборку фронта.
При замене EXE используйте временное имя, затем переименование готового файла.
Пересобирать фронт при последующих обновлениях только установщика не требуется.
